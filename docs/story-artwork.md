# Story artwork

The prologue uses the existing blue-cloaked explorer and generates new assets in the same chibi family: large rounded heads, tiny bodies, simple glossy oval eyes, soft 3D toy-like materials, and warm leather/brass accents. Painterly realistic concepts were rejected and are not shipped.

All four files below were created with the built-in image generation tool on September 9, 2026 and copied into the repository unchanged. The guide, lantern and tree preserve their transparent backgrounds. The scene is decorative; accessible HTML contains every playable cell, clue, objective and control.

Reference files are the project's original assets in `public/assets/dungeon/`. The new outputs are original characters and props, not copies of characters from another game. CSS controls display size and reduced-motion effects; no image contains hidden game information or required instructional text.

## Guide prompt

Create a NEW original guide NPC game sprite matching these reference game assets EXACTLY in art direction. First reference is the existing player, second is its workshop prop: cute 3D rendered toy-like chibi, huge round head, tiny round body and short limbs, warm ivory skin with two simple glossy dark oval eyes and NO realistic facial details, soft handcrafted/clay/fabric material, brass and leather accents, high-angle three-quarter view facing RIGHT. Guide wears forest-green hood and cloak with cream scarf and small brass lantern, brown backpack, holds a rolled trail map. Whole character from head to boots visible, centered, large silhouette with generous margin. Same head-to-body proportions as reference blue player; NOT a human realistic portrait, NOT painterly illustration. Fully transparent RGBA background, no floor or scenery, no text, no grid, no frame. A single polished readable chibi NPC suitable on the same Minesweeper game board as the referenced player.

## Camp banner prompt

Create a wide horizontal 1536x1024 original game branding illustration for Minefarer using exactly the cute 3D toy-like CHIBI visual style of these game reference assets. A compact miniature forest camp diorama, rounded handcrafted wood workshop and cream canvas tents, brass lanterns glowing softly, rounded trees and gentle pale hills, a path made of square puzzle-like paving stones, one tiny warning flag. The referenced blue cloaked round chibi traveler (huge round hooded head, tiny body, very short limbs, simple glossy oval eyes, no realistic anatomy) walks with a similar green-hooded chibi guide toward the camp. All trees, buildings, props miniaturized, rounded and toy-like, consistent with the 3D workshop reference. Warm ivory background with sage foliage and restrained gold accents. Airy uncluttered composition, main diorama centered-right, left upper portion light cream negative space for HTML title. NO realistic landscape, NO realistic people, NO painterly canvas style, NO busy HUD, NO text or lettering. Friendly polished 3D game asset aesthetic, soft shadows, crisp silhouettes.

## Trail lantern prompt

Create ONE transparent game prop sprite matching this reference's cute polished 3D toy-like fantasy game style, ivory stone, handcrafted wood, warm brass and soft materials. A modest trail lantern on a short wooden post beside two rounded pale paving stones. The lantern glows warm golden, with a little unlettered wooden direction arrow pointing right, friendly and welcoming, NOT a weapon, no characters. Three-quarter high-angle view, entire object in frame with 10% margin, centered, clear at 40px. True transparent RGBA background, no floor plane outside its tiny base, no text or letters. This marks an exit to the next scene in a chibi Minesweeper adventure.

## Tree prompt

Create ONE transparent game terrain sprite in the same cute polished 3D toy-like fantasy style as this reference. One small rounded miniature evergreen tree, three soft rounded layered sage-green foliage tiers, tiny warm brown trunk and small ivory moss base. Simple chunky clean silhouette, soft clay-like and handcrafted material, three-quarter high-angle view, muted sage to forest green, soft daylight. Entire object centered inside canvas with 10% margin. A board boundary decoration for a friendly chibi Minesweeper adventure. True transparent RGBA background, no landscape or flat ground plane, no characters, no text, no grid, no frame.
