# Dungeon artwork

Generated on September 4, 2026 with the built-in image generation tool, one call per asset, without reference images. Each selected PNG is copied unchanged into `public/assets/dungeon/`; CSS controls display size. Transparency is preserved. These are original project assets under the repository MIT license.

The nine assets share cobalt, ivory and brass colors with the existing interface. Key cells retain textual accessible labels; clues and inventory counts are real text. Covered mine positions are never illustrated before defeat.
