# Dungeon artwork

The original nine assets were generated on September 4, 2026 with the built-in image generation tool, one call per asset, without reference images. The profession variants documented below use the original Explorer as a style reference. Each selected PNG is copied unchanged into `public/assets/dungeon/`; CSS controls display size. Transparency is preserved. These are original project assets under the repository MIT license.

The original assets share cobalt, ivory and brass colors with the existing interface. Profession variants add teal and amber accents for recognition. Key cells retain textual accessible labels; clues and inventory counts are real text. Covered mine positions are never illustrated before defeat.

## Profession variants

The existing `player.png` remains the Explorer. The Surveyor and Engineer were generated on September 4, 2026 with the built-in image tool, using that Explorer as a style reference. Their selected PNGs are copied unchanged into the asset directory. Both contain real transparent alpha. These variants share the original clay style while using distinct silhouettes and equipment; they appear on the profession cards and the walking pawn. Text labels remain the accessible source of each profession's name.

This covers the three currently playable professions. Future professions, skill artwork and Boss assets remain in [Roadmap #1](https://github.com/shipiyouniao/Minesweeper-2.0/issues/1).

### `surveyor.png`

![Surveyor](../public/assets/dungeon/surveyor.png)

Reference: `public/assets/dungeon/player.png`.

Use case: stylized-concept. Create one production PNG character sprite for the Surveyor profession in a minimal Minesweeper roguelite. Use the reference only for the established beautiful restrained 3D clay/ceramic miniature style, rounded ivory body, large simple dark eyes, proportions, three-quarter front orthographic view and soft upper-left studio light. The Surveyor is a distinct friendly little character wearing a teal survey cap and short teal field jacket, brass goggles resting on the cap, brown boots and a small map backpack, holding one chunky ivory-and-cobalt handheld radar scanner. Give this profession a clear cap-and-scanner silhouette that remains readable at 32 pixels. Use large clean shapes, few details, no writing on the scanner. Center one complete full-body character with every limb visible, occupying about 80 percent of a square canvas with transparent margins. Actual transparent alpha background, isolated subject, no ground plane, no surrounding scene, no words, no watermark, no border. This is a new Surveyor asset; leave the referenced Explorer image unchanged.
