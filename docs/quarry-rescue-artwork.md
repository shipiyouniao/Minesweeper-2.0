# Old-mine rescue artwork

Two original assets were generated with the built-in image generation tool on September 10, 2026. Each was generated separately, without a reference image, and the chosen transparent PNG is stored unchanged. The existing Nia sprite was inspected to match the game's rounded chibi cast.

| Asset                              | Uses                                                              |
| ---------------------------------- | ----------------------------------------------------------------- |
| `public/assets/story/minecart.png` | Quarry entrance, cart, controls and illustrated guide             |
| `public/assets/story/toma.png`     | Passenger, dialogue portrait, camp resident and illustrated guide |

Rails, numbered branches, brake symbols and route forecasts are local SVG/HTML. They describe actual public game state and are not baked into an illustration. Accessible text carries all gameplay information.

## Minecart prompt

Create one original game sprite for Minefarer, a cozy chibi Japanese fantasy Minesweeper adventure. A small empty wooden minecart with chunky dark iron wheels, brass corner brackets and a single jade green brake handle. Three quarter view facing right, slightly from above, all wheels and rim visible. Handcrafted soft rounded toy-like painted 3D illustration, warm subdued colors, strong readable silhouette at 48px. One isolated cart only centered in a square frame, no tracks, no environment, no text, no border, no floor shadow. Real transparent alpha background. Leave modest transparent padding. Empty cart interior so the game can layer a rescued passenger. No photorealism, no tiny decorative clutter.

## Toma prompt

One original full-body chibi game character sprite, a young adult male mine mechanic named Toma for Minefarer, a cozy Japanese fantasy adventure. Big rounded head, small sturdy body, friendly tired expression, tousled dark brown hair, ochre miner helmet with unlit brass lamp, olive work overalls, cream shirt, leather gloves and brown boots, small red neckerchief. Holding a folded lunch cloth in one hand and a short wrench at his belt. One boot has a clean white bandage wrapped around the ankle (minor sprain, no blood). Standing calmly, three-quarter view facing right, all limbs and feet visible. Handcrafted soft rounded toy-like painted 3D illustration with large simple dark eyes, matching a chibi storybook cast, warm subdued colors and readable silhouette at 48px. Only this one character centered in a square frame with modest padding. Real transparent alpha background, no environment, no text, no border, no ground shadow, no extra people, no realistic human proportions.
