# Chapter finale artwork

`public/assets/story/control-console.png` is an original raster sprite generated with the built-in image-generation tool. Its transparent output is retained intact. It is used on the control-room doorway, powered line consoles and illustrated device guides. Existing chibi Nia, Lumi, profession and Bastion assets supply the cast; the guardian was not redesigned.

The northwest river, bridge planks and atlas roads extend the project's existing CSS/SVG geographic artwork. The bridge-lowering illustration is code-native geometry so the accepted restoration event can animate it directly.

## Generation prompt

> Use case: stylized-concept. Create one original game inventory/board sprite for Minefarer: a squat chibi fantasy power-routing control console on a small square weathered stone plinth, viewed from three-quarter above. Chunky brass housing and dark jade green enamel, a single large luminous emerald crystal at the back, two clearly readable mechanical lever handles on the sloping front. Hand-painted Japanese fantasy RPG item style, rich but restrained shading and thick readable shapes, cute proportions consistent with a chibi adventurer game. Centered complete object with generous transparent padding, genuine transparent alpha background. No character, no room, no letters, no words, no modern screen, no logos. Readable at 48 pixel board-cell size. The console is a distinct new asset, with a compact rectangular silhouette and no pump or water.

No external character, franchise image, texture or logo was included in this prompt. Generation used the built-in tool, not a fallback API script.
