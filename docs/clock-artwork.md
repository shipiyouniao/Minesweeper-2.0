# Clock artwork

Both original PNG assets were generated with the built-in image generation tool for this repository. No external art was copied. The generated alpha is preserved; spell rings, countdowns, echo tint and phase states are rendered by board code/CSS.

| Asset                                       | Use                                                                  |
| ------------------------------------------- | -------------------------------------------------------------------- |
| `public/assets/dungeon/clock-mage.png`      | Boss portrait and central board actor; tinted recovery/defeat states |
| `public/assets/dungeon/clock-hourglass.png` | Numbered single-use return mechanism, with a dimmed spent state      |

## Mage prompt

Use case: stylized-concept. One production transparent PNG game sprite: Clock Mage, a floating damaged ivory ceramic clock shell enclosing a dark hooded face with two cyan eyes, large brass clock hands over its shoulders, navy cloak and a glowing blue hourglass held in front. Chunky polished toy-like 3D fantasy, restrained minimal shapes readable at 48px, consistent ivory/navy/brass dungeon miniatures. Full figure centered, generous 10% margins, isolated genuinely transparent alpha background. No text, numbers, scenery, border or watermark. Return local saved image.

## Hourglass prompt

Use case: stylized-concept. One isolated game mechanism sprite: a squat ivory ceramic and brass hourglass pedestal with luminous cyan sand and two broad brass curved arrows around the glass, chunky polished toy-like 3D fantasy miniature for a minimal tactical minesweeper dungeon. Readable at 48px, few large shapes, centered full object with 10% margin. Genuine transparent alpha background, no scene, floor, text, numbers, frame or watermark. Return saved local image.
